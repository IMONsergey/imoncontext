# IMON Scale Diagnostic

Статический интерфейс стратегической диагностики IMON.

## Возможности

- 6 тематических разделов;
- 48 вопросов разных типов;
- сохранение прогресса в `localStorage`;
- проверка обязательных ответов;
- расчёт семи измерений готовности;
- определение наиболее согласованной модели масштабирования;
- локальный экспорт полного JSON;
- GitHub-only фиксация результата через Issue и GitHub Action.

## Поток сохранения

1. Пользователь завершает диагностику.
2. Интерфейс формирует компактный JSON без чувствительных финансовых полей.
3. Кнопка открывает предзаполненный GitHub Issue.
4. После подтверждения Issue workflow `capture-diagnostic.yml` валидирует пакет.
5. Workflow сохраняет `.json` и `.md` в `submissions/diagnostics/`, комментирует commit и закрывает Issue.

Токены, внешние базы и Supabase не используются.
