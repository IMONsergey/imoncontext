# Диагностические сессии IMON

В эту директорию GitHub Action сохраняет результаты, отправленные через IMON Scale Diagnostic.

Каждая сессия создаёт два файла:

- `.json` — структурированный пакет ответов и рассчитанный профиль;
- `.md` — человекочитаемое резюме для анализа и обсуждения.

## Важно о конфиденциальности

Репозиторий в текущем состоянии публичный. Не следует отправлять сюда коммерческую тайну, персональные данные, договорные условия, точные финансовые показатели и другую чувствительную информацию.

Интерфейс исключает поля, помеченные как чувствительные, из GitHub-пакета. Полная версия может быть выгружена локально в JSON.
