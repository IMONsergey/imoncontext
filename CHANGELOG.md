# Changelog

Все существенные изменения корпоративного контекста фиксируются здесь.

## 2026-08-06 — v0.2.0

### Добавлено

- Интерактивная стратегическая диагностика IMON на GitHub Pages.
- 48 вопросов по модели компании, предложениям, продажам, маркетингу, международному выходу и масштабированию.
- Автосохранение незавершённой сессии в браузере.
- Расчёт семи измерений готовности и пяти моделей масштабирования.
- Экспорт полного результата в JSON.
- GitHub-only фиксация ответов через Issue и GitHub Action.
- Автоматическое сохранение сессий в `submissions/diagnostics/`.
- Исключение чувствительных финансовых полей из публичного GitHub-пакета.
